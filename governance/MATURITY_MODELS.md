# 📈 Modelo de Maturidade MesaFlow (MF-CMMI)

Este documento define os níveis de maturidade técnica e de governança para os domínios do ecossistema.

---

## 1. Níveis de Maturidade
| Nível | Nome | Descrição |
| :--- | :--- | :--- |
| **L1** | **Initial** | Processos ad-hoc, dependência de intervenção manual. |
| **L2** | **Managed** | Tasks documentadas, uso básico de protocolos (INDA). |
| **L3** | **Defined** | DoD Global ativo, checklists padronizados, RFCs obrigatórias. |
| **L4** | **Quantitatively Managed** | Métricas de governança rastreadas (GOVERNANCE_METRICS.md). |
| **L5** | **Optimizing** | Auto-correção via IA, auditoria contínua, Chaos Governance. |

## 2. Status Atual por Domínio (Jan/2026)
- **Governance:** L4 (Métricas definidas, aguardando automação).
- **Backend:** L3 (Hardening de Enums e RLS concluídos).
- **Mobile:** L2 (Infra estabilizada, aguardando padronização de componentes).
- **AI:** L1 (Implementada, aguardando RFC-011 de limites).
