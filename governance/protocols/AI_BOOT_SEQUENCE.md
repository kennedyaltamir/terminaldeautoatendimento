# 🚀 AI Boot Sequence Protocol
**Version:** 1.0.0
**Authority:** MesaFlow Kernel

Este documento define a ordem obrigatória de ingestão de dados para qualquer IA que inicie uma sessão neste repositório. Ignorar esta ordem resulta em alucinação arquitetural.

## 📥 Sequência de Leitura
1. **`MASTER_PROJECT_SPECIFICATION.md`**: Visão geral e regras de negócio.
2. **`governance/prompts/AI_ARCHITECTURAL_HANDOFF.md`**: O protocolo de como você deve pensar e julgar.
3. **`project-ai-context.json`**: A Fonte da Verdade factual (Métricas e Dependências).
4. **`project-ai-context.md`**: O resumo executivo das falhas e hotspots.
5. **`architecture.mmd`**: O modelo mental espacial do sistema.

## ⚙️ Estado Pós-Boot
Após a ingestão, a IA deve emitir um `BOOT_COMPLETE` e aguardar instruções, assumindo o papel de **Juiz Arquitetural**.
