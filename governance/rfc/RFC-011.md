
# RFC-011: AI Operational Limits & Resource Policy
**Status:** ACTIVE
**Version:** 1.0
**Domain:** AI_ENGINEERING / INFRASTRUCTURE
**Date:** 2026-01-11

## 1. Objetivo
Definir as restrições de hardware e tempo para a execução de modelos de Inteligência Artificial (IA) no MesaFlow, garantindo que o motor preditivo não degrade a performance da API transacional.

## 2. Limites de Recursos (Sandbox)
Todo processo de IA deve operar dentro dos seguintes thresholds:

| Recurso | Limite Máximo | Ação ao Exceder |
| :--- | :--- | :--- |
| **Memória RAM** | 512 MB | SIGKILL imediato. |
| **Tempo de CPU** | 30 segundos | Timeout Exception. |
| **Dataset Size** | 10.000 registros | Truncamento de dados. |

## 3. Política de Fallback (Degradação Graciosa)
Caso o motor de IA falhe ou atinja um limite de recurso, o sistema deve:
1.  **Logar o Incidente:** Registrar `AI_RESOURCE_EXCEEDED` no Kernel Journal.
2.  **Fallback Heurístico:** Utilizar a média móvel simples (Simple Moving Average) para fornecer uma resposta básica ao usuário.
3.  **Silent Fail:** O erro de IA nunca deve retornar 500 para o cliente final; deve retornar um status `prediction_unavailable`.

## 4. Governança de Treinamento
- **Async Only:** É proibido realizar treinamento de modelos de forma síncrona durante uma requisição HTTP.
- **Worker Isolation:** O treinamento deve ocorrer em processos separados (Celery Workers) com prioridade `LOW`.
