
# RFC-001: Context Bundle Standard
**Status:** ACTIVE
**Version:** 1.0
**Domain:** BOOTLOADER

## 1. Definição
O **Context Bundle** (`todososarquivos.txt`) é a representação serializada do estado atual do projeto. Ele é a única entrada sensorial permitida para a IA.

## 2. Especificação de Formato
O arquivo deve seguir estritamente a estrutura de blocos delimitados:

```text
[[MESAFLOW_BEGIN:path/to/file.ext]]
# DOMAIN: <DOMAIN_ENUM>
# LAST_MODIFIED: <TIMESTAMP>
<CONTENT_BODY>
