# 🗺️ Mapeamento Funcional: Web vs Mobile

| Funcionalidade | Web Admin | App Mobile | Prioridade Mobile |
| :--- | :---: | :---: | :--- |
| Configuração de Cardápio | ✅ Sim | ❌ Não | Baixa |
| Lançamento de Pedidos | ✅ Sim | ✅ Sim | **Crítica (UX Rápida)** |
| Gestão de Estoque (Entrada) | ✅ Sim | ❌ Não | Baixa |
| KDS (Monitor de Cozinha) | ✅ Sim | ✅ Sim | Média (Tablets) |
| Rastreamento de Entrega | ❌ Não | ✅ Sim | **Crítica (GPS)** |
| Relatórios Financeiros | ✅ Sim | ⚠️ Resumo | Média |
| Notificações Push | ❌ Não | ✅ Sim | **Crítica** |

## Decisões Estratégicas
- **Mobile-First:** O fluxo do entregador e do garçom deve ser desenhado primeiro para o App.
- **Web-Only:** Configurações fiscais, importação de XML e design de temas permanecem exclusivos da Web.
