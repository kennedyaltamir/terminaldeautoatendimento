# 🛵 Manual de Logística e Delivery

Este guia explica como operar o módulo de entregas do MesaFlow, desde o cadastro da frota até a entrega final ao cliente.

---

## 1. Configuração da Frota (Gerente)

Antes de despachar pedidos, você precisa cadastrar quem vai levá-los.

1.  Acesse o Painel Admin > **Equipe**.
2.  Clique em **"Adicionar Membro"**.
3.  Preencha Nome e Email do entregador.
4.  Em Função, selecione **"Entregador (Motoboy)"**.
5.  Defina uma senha simples (ex: 123456) e entregue ao motorista.

---

## 2. Fluxo de Despacho (Gerente/Expedição)

Quando um pedido de Delivery fica pronto na cozinha:

1.  Acesse o menu **Delivery** (ícone de Moto).
2.  Você verá a lista de pedidos com status **"Pronto"** (Verde).
3.  Clique em **"Iniciar Entrega"**.
4.  Uma janela abrirá perguntando: *"Quem vai levar?"*.
5.  Selecione o entregador disponível na lista.
6.  Clique em **"Iniciar Entrega"**.
    *   O status do pedido muda para **"Em Rota"** (Azul).
    *   O cliente recebe um WhatsApp: *"Saiu para entrega!"*.

---

## 3. App do Entregador (Motoboy)

O entregador não usa o painel completo. Ele tem uma interface simplificada.

**Acesso:** `mesaflow.com/admin/login` (Entrar com email/senha do motoboy).

### Tela "A Retirar"
Mostra os pedidos que já foram atribuídos a ele ou que estão prontos aguardando alguém pegar.
*   **Ação:** Clicar em **"Pegar Pedido"** para confirmar que está com o pacote em mãos.

### Tela "Em Rota"
Lista as entregas que estão na bag.
*   **Botão GPS:** Abre o Waze ou Google Maps direto no endereço do cliente.
*   **Botão WhatsApp:** Abre conversa com o cliente sem precisar salvar o número.
*   **Botão Confirmar:** Finaliza a entrega.

---

## 4. Dicas Operacionais

*   **Sem Entregador Fixo:** Se você usa apps terceirizados (Uber Flash/Lalamove), na hora de despachar, selecione a opção **"Sem Entregador"**. O pedido ficará como "Em Rota" sem vínculo com funcionário.
*   **Geolocalização:** O botão de GPS usa o endereço cadastrado pelo cliente. Se o endereço for impreciso, o entregador deve usar o botão de WhatsApp para pedir a localização fixa.
