## 1. Para o Gestor
### Configuração Inicial
1.  Acesse **Configurações > Geral** para definir logo, cores e horários.
2.  Em **Cardápio**, crie Categorias e Produtos. Use "Grupos de Opções" para adicionais.
3.  Em **Mesas**, gere os QR Codes e imprima.

### Financeiro
- Acompanhe o **Dashboard** para ver vendas em tempo real.
- Configure sua conta bancária em **Configurações > Financeiro** para receber os repasses do Pix.

---

## 2. Para a Cozinha
### Operação do KDS
- **Tela:** Use um tablet ou monitor touch.
- **Cores:**
    - 🟢 Verde: Pedido novo (< 10 min).
    - 🟡 Amarelo: Atenção (10-20 min).
    - 🔴 Vermelho: Atrasado (> 20 min).
- **Ação:** Toque no card para "Iniciar Preparo". Toque novamente para "Finalizar".
- **Estoque:** Se acabar um item, clique no ícone de **Caixa** no topo e bloqueie o produto imediatamente.

---

## 3. Para o Garçom
### App Mobile
- **Login:** Use seu email e senha cadastrados pelo gerente.
- **Abrir Mesa:** Toque em uma mesa livre e informe o nome do cliente.
- **Lançar Pedido:** Selecione os itens. O envio para a cozinha é instantâneo.
- **Fechar Conta:** Clique em "Pagamento". O sistema calcula o total e gera o Pix ou permite baixa em dinheiro.

---

## 4. Para a Logística
### App do Entregador
- Acesse a aba **"A Retirar"** para pegar pedidos prontos.
- Clique em **"Iniciar Rota"** para avisar o cliente.
- Use o botão **"Waze"** para navegar.
- Na entrega, peça o **Código de Confirmação** ao cliente e digite no app para finalizar.
