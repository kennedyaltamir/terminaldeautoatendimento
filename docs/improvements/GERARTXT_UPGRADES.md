# 🚀 Melhorias para o Gerador de Contexto (`gerartxt.py`)

Lista de funcionalidades planejadas para a versão 3.0 do script de contexto.

1.  **Estimativa de Tokens:** Exibir contagem estimada (`chars / 4`) ao final.
2.  **Filtro de Tamanho:** Ignorar arquivos > 500KB automaticamente.
3.  **Mapa Visual:** Incluir árvore de diretórios ASCII no cabeçalho.
4.  **Modo Foco:** Argumento `--dir app/routers` para contexto parcial.
5.  **Scanner de Segredos:** Alerta de API Keys hardcoded.
6.  **Minificação Leve:** Remover linhas em branco consecutivas.
7.  **Metadados:** Incluir timestamp de modificação por arquivo.
8.  **Integração Git:** Respeitar regras do `.gitignore`.
9.  **Resumo de Deps:** Extrair apenas `dependencies` de `package.json`.
10. **Clipboard:** Copiar saída automaticamente com `pyperclip`.
