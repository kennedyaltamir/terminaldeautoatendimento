# 🍔 Melhorias: Engenharia de Cardápio
1. **Smart Upselling:** Sugestões automáticas no carrinho.
2. **Preços Dinâmicos:** Alteração automática por horário (Happy Hour).
3. **Tags de Dieta:** Filtros para Veganos, Sem Glúten, etc.
4. **Gestão de Combos:** Lógica de "Monte seu prato".
5. **Fotos em Alta Resolução:** Pipeline de compressão WebP.
6. **Descrições por IA:** Gerador de textos persuasivos.
7. **Destaques de Venda:** Selos de "Mais Pedido" ou "Chef Recomenda".
8. **Ordenação por Rentabilidade:** Algoritmo que prioriza itens com maior margem.
9. **Menu Multilíngue:** Tradução automática via API.
10. **QR Code Design:** Personalização visual do código impresso.
