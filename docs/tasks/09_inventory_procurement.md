# 📦 Melhorias: Estoque & Compras
1. **Importação de XML:** Entrada de nota fiscal automática.
2. **Custo Médio Ponderado:** Cálculo real de margem de lucro.
3. **Alerta de Estoque Mínimo:** Notificação push/e-mail.
4. **Gestão de Desperdício:** Registro de quebras e perdas.
5. **Ficha Técnica Multinível:** Ingredientes dentro de sub-receitas.
6. **Ordens de Compra:** Geração de PDF para fornecedores.
7. **Histórico de Preços:** Gráfico de variação de custo de insumos.
8. **Inventário Cego:** Módulo para conferência de estoque físico.
9. **Validade de Lotes:** Alerta para produtos próximos ao vencimento.
10. **Integração com Fornecedores:** Portal para cotação direta.
