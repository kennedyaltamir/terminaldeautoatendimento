# 📱 Melhorias: App do Garçom (Mobile POS)
1. **Quick-Action Bar:** Atalhos para itens mais vendidos.
2. **Haptic Feedback:** Vibrações para alertas e confirmações.
3. **Offline Buffer:** Lançamento de pedidos sem internet.
4. **Leitura de QR Code:** Identificação rápida de mesas.
5. **Calculadora de Troco:** Integrada no fechamento em dinheiro.
6. **Modo Noturno:** Interface otimizada para ambientes escuros.
7. **Venda Balcão Rápida:** Fluxo sem necessidade de mesa.
8. **Transferência de Itens:** Mover pratos entre mesas.
9. **Alerta de Pedido Pronto:** Notificação visual e sensorial.
10. **Busca por Voz:** Localização de produtos via comando de voz.
