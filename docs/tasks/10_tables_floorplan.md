# 🪑 Melhorias: Mesas & Salão
1. **Mapa de Sala Visual:** Drag & Drop para layout real.
2. **Reserva de Mesas:** Calendário integrado com o cardápio.
3. **Split Bill Avançado:** Divisão por item ou valor exato.
4. **Timer de Ocupação:** Alerta visual para mesas paradas.
5. **Status de Limpeza:** Fluxo entre "Livre", "Ocupada" e "Sujou".
6. **Vínculo de Comanda Física:** Leitura de código de barras.
7. **Pré-pagamento:** Exigir sinal para abrir mesa em eventos.
8. **Múltiplos Garçons:** Atendimento compartilhado por zona.
9. **Integração com Sensores:** Detecção de presença física (IoT).
10. **Histórico de Mesa:** Ver o que foi consumido naquela posição no dia.
