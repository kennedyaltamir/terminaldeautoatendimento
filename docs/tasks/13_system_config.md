# ⚙️ Melhorias: Configurações & Sistema
1. **White-label DNS:** Uso de domínios próprios com SSL automático.
2. **Editor de Temas:** Customização de fontes e bordas.
3. **Configuração de Impressão:** Mapeamento de impressoras por praça.
4. **Webhooks de Saída:** Notificar sistemas externos sobre pedidos.
5. **Backup Externo:** Exportação automática para S3/Google Drive.
6. **Modo Manutenção:** Aviso programado para o cardápio.
7. **SEO Settings:** Meta tags para o cardápio público.
8. **Integração de Pixel:** Facebook e Google Analytics.
9. **Termos de Uso Custom:** Editor de políticas de privacidade.
10. **API Keys:** Gestão de tokens para integrações de terceiros.
