# 🔒 Proteção de Dados e Conformidade LGPD

## 1. Governança de Dados

### 1.1 Papéis e Responsabilidades
- **Controlador:** O Cliente Enterprise (Estabelecimento) que utiliza a plataforma.
- **Operador:** MesaFlow, atuando como processador de dados sob instrução do Controlador.

### 1.2 Base Legal
O tratamento de dados pessoais na plataforma é realizado sob as bases legais de:
- **Execução de Contrato:** Para processamento de pedidos e entregas.
- **Obrigação Legal:** Para emissão de documentos fiscais.
- **Legítimo Interesse:** Para prevenção de fraudes e segurança.

## 2. Ciclo de Vida dos Dados

### 2.1 Coleta
Minimização de dados: Coletamos apenas o estritamente necessário para a operação (Nome, Telefone para contato/fidelidade, Endereço para entrega).

### 2.2 Armazenamento
Os dados são armazenados em infraestrutura certificada (SOC2/ISO 27001), com criptografia em repouso.

### 2.3 Retenção e Descarte
- **Logs Técnicos:** Retidos por 6 meses (Marco Civil da Internet).
- **Dados Fiscais:** Retidos por 5 anos (CTN).
- **Dados Operacionais:** Retidos enquanto a conta do cliente estiver ativa ou até solicitação de exclusão.
- **Descarte:** Processo automatizado de exclusão segura mediante solicitação via canal de privacidade.

## 3. Direitos dos Titulares
O MesaFlow fornece ferramentas para que o Controlador atenda às solicitações dos titulares:
- **Acesso:** Exportação de dados em formato legível (JSON/CSV).
- **Exclusão:** Funcionalidade de anonimização de dados de clientes inativos.
- **Correção:** Interface de autoatendimento para atualização cadastral.

## 4. Transferência Internacional
Os dados podem ser processados em servidores localizados nos Estados Unidos (AWS), garantidos por Cláusulas Contratuais Padrão (SCC) e conformidade dos fornecedores com frameworks de privacidade globais.
