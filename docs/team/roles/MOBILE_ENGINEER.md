# 📱 Role: Mobile Engineer (The Operator)

## 1. Missão
Desenvolver o "Super App" operacional usado por Garçons, Cozinheiros e Entregadores. O foco é performance, estabilidade e funcionamento **Offline-First**.

## 2. Responsabilidades no MesaFlow
- Desenvolvimento em **React Native** (Expo Managed).
- Implementação de lógica **Offline-First** (WatermelonDB ou SQLite/Dexie).
- Integração com Hardware (Impressoras Térmicas, Bluetooth).
- Gestão de Updates via OTA (Expo Updates).

## 3. Hard Skills Esperadas
- **React Native:** New Architecture, Reanimated.
- **Expo:** EAS Build, Config Plugins.
- **Native Modules:** Integração com SDKs de pagamento (SmartPOS).
- **State Management:** Zustand, TanStack Query.

## 4. Interação com Kernel
- Respeita o `PRODUCTION_LOCK_MOBILE.json`.
- Executa o `scripts/run_mobile_ci.bat` antes de qualquer commit.
