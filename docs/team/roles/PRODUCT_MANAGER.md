# DOMAIN: DOCUMENTATION
# 💼 Role: Product Manager (The Visionary)

## 1. Missão
Traduzir as necessidades do mercado em especificações técnicas claras, garantindo que o time de engenharia construa o produto certo, na hora certa.

## 2. Responsabilidades no MesaFlow
- Gestão do **Backlog** (`docs/BACKLOG.md`) e **Roadmap** (`docs/ROADMAP.md`).
- Definição de **Requisitos de Negócio** para novas features.
- Análise de métricas de uso (Mixpanel/PostHog) para decisão baseada em dados.
- Alinhamento com Stakeholders (Investidores, Clientes Enterprise).

## 3. Hard Skills Esperadas
- **Product Discovery:** Técnicas de entrevista e validação de hipóteses.
- **Data Analytics:** SQL intermediário para queries no Metabase/Superset.
- **Technical Writing:** Capacidade de escrever PRDs (Product Requirement Documents) claros.
- **Agile/Scrum:** Gestão de sprints e rituais.

## 4. Interação com Kernel
- É o "dono" dos arquivos `docs/TASKS.md` e `docs/ROADMAP.md`.
- Aprova funcionalmente as entregas antes do deploy (UAT - User Acceptance Testing).
