# 📱 Manual do App do Garçom (Mobile POS)

O MesaFlow inclui uma interface exclusiva para a equipe de salão, desenhada para ser usada em celulares com agilidade e precisão.

**Acesso:** `mesaflow.com/admin/login` (Entrar com perfil de Garçom ou Gerente).

---

## 1. Visão Geral e Navegação
A interface é dividida em três áreas principais:
1.  **Salão (Mesas):** Mapa visual das mesas (Livres/Ocupadas).
2.  **Pedidos:** Lista de todos os pedidos ativos e seus status na cozinha.
3.  **Ações Rápidas:** Botões no topo para vendas sem mesa (Balcão/Delivery).

---

## 2. Atendimento nas Mesas
### Abrindo uma Mesa
1.  Toque em uma mesa **Verde (Livre)**.
2.  Digite o nome do cliente (Opcional, mas recomendado).
3.  Toque em "Abrir Mesa".

### Lançando Pedidos
1.  Dentro da mesa, use a **Barra de Busca** ou os botões de **"Mais Vendidos"** no topo (ex: Água, Cerveja) para agilidade.
2.  Toque no produto para adicionar ao carrinho.
3.  Toque em "Ver Pedido" para conferir ou adicionar observações (ex: "Sem gelo").
4.  Clique em **"Enviar"**. O pedido aparecerá instantaneamente na tela da Cozinha (KDS).

### Fechando a Conta
1.  Na tela da mesa, toque no botão **"Fechar Conta"** (Ícone de Cartão).
2.  Selecione o método: Dinheiro, Cartão ou Pix.
3.  **Dinheiro:** O sistema abrirá a **Calculadora de Troco**. Digite quanto o cliente deu, e o sistema mostra o troco exato.
4.  Ao confirmar, a mesa é liberada automaticamente.

---

## 3. Módulo QuickPOS (Balcão e Delivery)
Para vendas que não ocupam lugar no salão.

### 🛍️ Venda Balcão (Takeout)
Ideal para clientes que pedem para levar ou comem em pé.
1.  Na tela inicial, toque em **"Venda Balcão"**.
2.  Adicione os produtos.
3.  Finalize o pagamento imediatamente.
4.  O pedido vai para a cozinha identificado como "Balcão".

### 🛵 Novo Delivery
Para pedidos via telefone/WhatsApp.
1.  Na tela inicial, toque em **"Novo Delivery"**.
2.  Preencha: **Nome**, **Telefone** e **Endereço**.
3.  Lance os produtos e envie.
4.  Acompanhe o status na aba "Pedidos". Quando estiver pronto, o sistema avisa para despachar o motoboy.

---

## 4. Gestão Avançada de Mesas

### 🔄 Transferência de Mesa
O cliente mudou de lugar?
1.  Abra a mesa atual.
2.  Toque no ícone de **Transferência** (Setas Cruzadas).
3.  Selecione a mesa de destino.
4.  Confirme. Todos os pedidos mudam de lugar automaticamente.

### 🔗 Juntar Mesas (Merge)
Duas mesas decidiram juntar a conta?
1.  Faça o processo de transferência acima.
2.  Selecione uma mesa que **já está ocupada**.
3.  O sistema perguntará: *"Deseja JUNTAR as mesas?"*.
4.  Confirme. As comandas serão somadas em uma só.

---

## 5. Notificações Sensoriais
O celular do garçom é uma ferramenta de trabalho ativa.

*   **Pedido Pronto:** Quando a cozinha finaliza um prato, o celular **Vibra** e toca um som de alerta. Uma notificação aparece no topo: *"Mesa 10 - Pedido Pronto!"*.
*   **Chamado do Cliente:** Se o cliente escanear o QR Code e clicar em "Chamar Garçom", o celular vibra com um padrão diferente (Alerta de Urgência).
