# 👨‍🍳 Melhorias: Operação de Staff & KDS

Este arquivo define as melhorias que serão implementadas para otimizar o trabalho da equipe de salão e cozinha.

### Itens a Implementar:
1.  **Modo Quiosque (Kiosk):** Bloqueio de interface para tablets de autoatendimento fixos.
2.  **Feedback Haptic:** Vibrações diferenciadas no celular do garçom para alertas de urgência.
3.  **KDS Sectorization Refinement:** Lógica para produtos que pertencem a múltiplas praças simultaneamente.
4.  **PIN Auth para Garçons:** Sistema de login ultra-rápido para tablets compartilhados.
5.  **Mapa de Sala Drag & Drop:** Interface visual para organizar o layout das mesas.
6.  **Ledger de Insumos Real-time:** Alerta visual no KDS quando um ingrediente da ficha técnica acaba.
7.  **Staff Performance KPIs:** Relatórios de produtividade por funcionário.
8.  **Perfis de Som Customizados:** Sons diferentes para pedidos de Delivery vs Salão.
9.  **Impressão em Lote:** Fechamento de conta com impressão consolidada de múltiplos pedidos.
10. **Escalonamento de Chamados:** Alerta automático para o gerente se um chamado de mesa demorar a ser atendido.
