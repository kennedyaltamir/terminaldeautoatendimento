# 🛵 Melhorias: App do Entregador
1. **Proof of Delivery (POD):** Confirmação via foto ou código.
2. **Deep Linking Mapas:** Botão direto para Waze/Google Maps.
3. **Driver Ledger:** Controle de saldo devedor em dinheiro.
4. **Rastreamento GPS:** Localização em tempo real para o cliente.
5. **Fila de Despacho:** Ordem de saída justa para motoboys.
6. **Chat com Cliente:** Mensagens pré-definidas via WhatsApp.
7. **Relatório de KM:** Estimativa de distância percorrida.
8. **Assinatura Digital:** Coleta de rubrica na tela do celular.
9. **Modo Economia de Bateria:** Otimização do uso de GPS.
10. **Checklist de Saída:** Conferência de itens antes da rota.
