# 👥 Definição de Papéis e Competências (Dream Team)

Este documento define a estrutura organizacional necessária para operar o MesaFlow. Ele serve como guia de contratação e como mapa de responsabilidades para os Agentes de IA.

---

## 1. O Núcleo Estratégico (The Core)
Responsáveis pela governança, visão e estabilidade da plataforma.

### 🏛️ [Chief Architect (The Kernel)](./roles/ARCHITECT.md)
*   **Responsabilidade:** Guardião da integridade estrutural, decisões de stack e governança técnica (Protocolo INDA).
*   **Habilidades Hard:** Python Avançado, System Design, Cloud Architecture, Segurança (OAuth/JWT).
*   **Agente IA:** `The Architect`

### 💼 [Product Manager (The Vision)](./roles/PRODUCT_MANAGER.md)
*   **Responsabilidade:** Definição de roadmap, priorização de backlog e alinhamento com negócio.
*   **Habilidades:** Metodologias Ágeis, Análise de Dados (SQL/BI), User Discovery.
*   **Agente IA:** `The Strategist`

### 🛡️ [DevOps & SRE (The Shield)](./roles/DEVOPS_SRE.md)
*   **Responsabilidade:** Infraestrutura, CI/CD, Monitoramento e Segurança.
*   **Habilidades:** GitHub Actions, Docker, Terraform, Sentry, Postgres Tuning.
*   **Agente IA:** `The Guardian`

---

## 2. A Fábrica de Produto (The Factory)
Responsáveis pela construção das interfaces e lógica de negócio.

### ⚙️ [Backend Engineer (The Engine)](./roles/BACKEND_ENGINEER.md)
*   **Responsabilidade:** Lógica de negócios, APIs, integrações financeiras e performance.
*   **Habilidades:** Python (FastAPI), SQLAlchemy, Pydantic, Redis, Celery.
*   **Agente IA:** `The Executor (Backend)`

### 🎨 [Frontend Engineer (The Face)](./roles/FRONTEND_ENGINEER.md)
*   **Responsabilidade:** Experiência do usuário web, dashboards administrativos e PWA.
*   **Habilidades:** React, Next.js 14, TypeScript, Tailwind CSS, Zustand.
*   **Agente IA:** `The Executor (Frontend)`

### 📱 [Mobile Engineer (The Operator)](./roles/MOBILE_ENGINEER.md)
*   **Responsabilidade:** Aplicativo nativo para staff (Android/iOS) e operação offline.
*   **Habilidades:** React Native, Expo, Native Modules, Offline-first (Dexie/SQLite).
*   **Agente IA:** `The Executor (Mobile)`

---

## 3. Garantia de Qualidade (The Audit)

### 🧪 [QA Automation (The Hunter)](./roles/QA_AUTOMATION.md)
*   **Responsabilidade:** Garantia de qualidade, prevenção de regressão e testes de carga.
*   **Habilidades:** Playwright, Maestro, Pytest, Cenários de Borda.
*   **Agente IA:** `The Reviewer`
