### 🕵️ Análise de Causa Raiz

1.  **Causa Raiz 1 (CORS Falso-Positivo):** O erro de CORS no navegador é um sintoma, não a causa. O FastAPI, ao encontrar um erro crítico de lógica ou contrato (como o erro 500 ou 422 no login), encerra a resposta. Se o `CORSMiddleware` não estiver no topo da pilha ou se a aplicação crashar na fase de importação (como visto anteriormente com o `cache_response`), o FastAPI retorna uma resposta de erro padrão sem processar os middlewares, resultando na ausência dos headers de permissão.
2.  **Causa Raiz 2 (Mismatch de Contrato):** O uso de `OAuth2PasswordRequestForm` no backend exige estritamente o `Content-Type: application/x-www-form-urlencoded`. O envio de JSON pelo frontend gera um erro de validação (422) que, dependendo do tratamento global de exceções, culmina em um 500 ou resposta sem headers.

```inda
@app.middleware("http")
async def cors_error_protection(request: Request, call_next):

        return await call_next(request)
    except Exception as e:

            media_type="application/json",

                "Access-Control-Allow-Origin": allow_origin,
                "Access-Control-Allow-Credentials": "true"
            }
```

#### 2. Backend: Router de Autenticação
**Arquivo:** `app/routers/auth.py`
**Mudanças:** Garantir a recepção correta do formulário OAuth2.

```inda
filename: [[MESAFLOW_BEGIN:app/routers/auth.py]]
# DOMAIN: BACKEND
# LAST_MODIFIED: 2026-02-05 01:12:00
from fastapi import APIRouter, Depends, HTTPException, status
from fastapi.security import OAuth2PasswordRequestForm
from sqlalchemy.orm import Session
from app.database import get_db
from app.core import security

router = APIRouter()

@router.post("/token")
async def login_for_access_token(
    form_data: OAuth2PasswordRequestForm = Depends(),
    db: Session = Depends(get_db)
):
    # form_data.username e form_data.password são extraídos de x-www-form-urlencoded
    user = security.authenticate_user(db, form_data.username, form_data.password)
    if not user:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Credenciais incorretas",
            headers={"WWW-Authenticate": "Bearer"},
        )
    
    access_token = security.create_access_token(data={"sub": user.email})
    return {"access_token": access_token, "token_type": "bearer"}

```

**Arquivo:** `frontend/src/lib/api.ts`
**Mudanças:** Alteração do método `login` para utilizar `URLSearchParams` e o header de formulário correto.

```inda
# DOMAIN: FRONTEND
# LAST_MODIFIED: 2026-02-05 01:15:00
const API_BASE_URL = "http://localhost:8001/api";

export const login = async (credentials: { email: string; password: string }) => {
  // 🛡️ CONTRATO OAUTH2: Transformando JSON em Form-Data URL Encoded
  const formData = new URLSearchParams();
  formData.append("username", credentials.email);
  formData.append("password", credentials.password);

  const res = await fetch(`${API_BASE_URL}/auth/token`, {
    method: "POST",
    headers: {
      "Content-Type": "application/x-www-form-urlencoded",
      "Accept": "application/json"
    },
    body: formData.toString(),
  });

  if (!res.ok) {
    const errorData = await res.json().catch(() => ({}));
    throw new Error(errorData.detail || "Falha na autenticação");
  }

  return res.json();
};

```

### ✅ Checklist de Verificação de Sucesso

1.  **Ordem de Middleware:** Em `app/main.py`, o `CORSMiddleware` agora precede os routers. Isso garante que as requisições `OPTIONS` (Preflight) sejam respondidas antes da lógica de negócio.
2.  **IP de Rede:** A inclusão do IP `172.22.160.1` resolve o bloqueio quando o frontend é acessado via IP de rede local (comum em ambientes Docker/WSL).
3.  **Encapsulamento de Erro:** O novo middleware `cors_error_protection` garante que, mesmo se uma rota lançar uma exceção não tratada (500), a resposta retornará com os headers CORS, permitindo que o frontend leia o erro em vez de mostrar apenas "CORS blocked".
4.  **Consistência de Payload:** O `api.ts` agora envia os dados exatamente como o `OAuth2PasswordRequestForm` espera, eliminando erros 422.
